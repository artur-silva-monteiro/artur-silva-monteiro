# Artur Silva Monteiro

Sou graduando em Estatística e Ciência de Dados na Universidade Federal do Espírito Santo (UFES).

Utilizo R em projetos acadêmicos de organização, análise exploratória e visualização de dados. Estou aprendendo a organizar e compartilhar esses trabalhos pelo GitHub.
